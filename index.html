About the Program

Bloomrix Web Development Internship

The internship teaches web development through daily tasks. Every task has a list of topics to study and an assignment to build. Each assignment is saved in a public GitHub repository with clear commits.

The first tasks cover HTML. They start with document structure and forms, and move on to tables, media, advanced form tags and a complete HTML project.

Every assignment is checked in the browser, and layouts are tested at mobile, tablet and desktop widths.

The later tasks cover CSS. They begin with selectors, colors and fonts, then move to the box model, Flexbox, Grid and responsive design.

The most recent task covers advanced CSS: variables, themes, cascade layers, container queries, animations and multi-column text.
